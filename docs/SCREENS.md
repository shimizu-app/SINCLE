# SYNCLE 画面仕様

デザインの見本は `syncle-v28.jsx`。ここには**動きと処理**を書く。

## 1. 起動

形が6種類（花→クローバー→太陽→六角→blob→しずく）0.26秒ごとに切り替わり、SYNCLEシンボルになる。文字と読み込み中の点が続く。

**重要**：アニメーションの時間を固定にしない。データの読み込みが終わり次第、シンボルに飛ばして次へ進む。`prefers-reduced-motion` のときは0.4秒で終わる。

## 2. 認証

### 入口

「ワークスペースにログイン」と「新しくワークスペースを作る」の2択。

### ログインの流れ

```
メール入力（またはGoogleでログイン）
  ↓ 6桁コード送信（Supabase Auth OTP）
コード入力
  ↓ 認証成功
所属ワークスペースを検索
  ├─ 1つ         → そのまま入る
  ├─ 複数        → 選択画面
  ├─ 同ドメインあり → 「同じ会社にあります」を表示。参加 or 申請
  └─ 0件         → 「参加できるワークスペースがありません」→ 新規作成へ
```

**事前登録の判定**：`workspace_members` に `email` が登録済み（status=invited）なら、ログイン時に `user_id` を紐づけて `status=active` にする。

**同ドメイン**：`workspaces.domain` がメールのドメインと一致するものを探す。`open_join=true` なら即参加、false なら `join_requests` に積む。

**招待リンク**：`/join/{token}` で開く。トークンが有効なら、認証後そのワークスペースに参加。`uses` をインクリメントし、`max_uses` に達したら無効化。

### 新規作成

会社名を入れると slug を自動生成（法人格と記号を除去、英小文字化）。重複チェックが必要。名前・役割・アイコンを設定して作成。

### ロック

`keepSignedIn` が有効ならセッションを保持。アプリを開くときに端末の生体認証（WebAuthn または Capacitor 経由のネイティブAPI）でロック解除する。設定でオフにできる。

## 3. 顧客

上部に3つの切り替え：**会社 / 進行中 / キーパーソン**

### 3-1. 会社

ヘッダーに件数（社数 / Tier A数 / 未完了タスク数）、メール（未返信バッジ）、＋追加、設定。

**表示形式の注意**：プロトタイプはスクロール連動のカードデッキ。件数が増えると使えないため、実装では以下のどちらかにする。

- 絞り込み結果10件以下 → デッキ、それ以上 → 通常リスト
- 全顧客リストは通常リスト固定。デッキは別の用途に取っておく

**検索**：会社名・担当者名・役職・部署・メール・業種・案件種別・タグを対象。
**並べ替え**：新しい順 / 古い順 / ティア順 / 進捗順 / 会社名順
**絞り込み**：ティア / 業種（31種）/ 案件種別（6種）

### 3-2. 進行中（案件）

`deals.active = true` のものを並べる。

**既定の並びは「止まっている順」**（`updated_at` の古い順）。

各カード：会社名、状況バッジ、案件種別、金額、担当アバター、メモ、最終更新からの日数。

**放置判定**：`SPEC.md` の 3章を参照。しきい値超えでオレンジ枠、2倍でオレンジ枠＋警告文。

タップでシートが開き、状況・種類・メモ・金額・担当を編集。**メモを更新したら `updated_at` を更新する**（これで放置判定がリセットされる）。「完了にする」で `active=false` にし、会社チャンネルにシステムメッセージを残す。

### 3-3. キーパーソン

紹介の多い順に並べる。

**絞り込みは4軸を組み合わせられる**（複数選択・AND条件）。

| 軸 | 選択肢 |
|---|---|
| ジャンル | IT・システム / 製造・建設 / 食品・飲食 / 医療・福祉 / 小売・EC / 広告・制作 / 金融・士業 / 物流・運送 / 行政・団体 / その他 |
| 影響範囲 | 全国 / 地方 / 県 |
| 県 | 47都道府県（登録のある県のみ表示） |
| どんな層に強いか | 大手の経営層 / 中小の経営者 / 部長・現場長 / 大学・研究者 / 行政・議員 / 金融・投資家 / メディア / 地域の集まり |

ジャンルは「本業」と「顔が利くジャンル（複数）」の両方で判定する。

**登録は2経路**：名刺から選ぶ / 手動で追加（顧客でない人も登録できる）。

詳細：出会い、どういう人か、どんな人脈か、**ご紹介いただいた先**（縦のタイムライン。結果ごとに色分け）。

## 4. 会社詳細

タブ7つ：**概要 / 履歴 / 名刺 / 書類 / タスク / メール / チャンネル**

ヘッダーは会社の色（業種から決まる）のアートヘッダー。

### 概要

クイックアクション4つ（メール / 日程調整 / 履歴 / タスク）、基本情報カード、確定した予定、編集フォーム。

### 履歴（タイムライン）

メール送受信・打合せ・タスク・完了タスク・チャンネル会話・システム更新を**1本の時系列**に並べる。

フィルタ：すべて / メール / 打合せ / タスク / 会話

**記録の入力欄を上部に置く。**「電話した」「訪問した」を1行で書ける。書いた内容はチャンネルにも流れる。これが入力を促す最大の仕掛けなので省略しない。

**実装の注意**：全イベントに `timestamp` を持たせて降順ソート。件数が増えるので「もっと見る」によるページングが必要。

### 名刺

この会社の contacts 一覧。窓口には星と黄色い枠。各カードに「メール」「窓口にする」、Gmail連携時は「メール取り込み中 / オフ」のトグル。下部に「スキャン」「手入力」。

### 書類

種類で絞り込み（契約書 / 見積書 / 提案書 / 請求書 / 仕様・資料 / その他）。「よく使う」（星）は上部固定。

アップロードは Supabase Storage へ。ファイル1件ごとに種類の変更とメモの編集ができる。

**入り口は3つ想定**：手動アップロード / メールの添付から取り込み / チャンネルに貼ったファイルの自動保存。

### タスク

進捗バーとステージ選択、タスク一覧（付箋型）、「＋ タスクを追加」。

### メール

「AIで下書きしてメールを作成」、メール履歴。未返信の受信メールには「タスクにする」「AIで返信」。

### チャンネル

会社ごとの社内チャット。上部に進捗と未完了タスク数、「進捗を見る」。

## 5. チャンネル

上部タブ4つ：**個人 / グループ / 会社 / メンバー**（それぞれ未読バッジ）

### 個人（DM）

上にメンバーのアイコンを横並び（タップでDMを開く）、下に会話中のスレッド。
DM画面はLINE型の吹き出し。自分は右の紫、相手は左の白。

### グループ

自由作成のチャンネル。作成時にアイコン（12種の形×色）とメンバーを選ぶ。
**絵文字は使わない。** SYNCLEのシェイプを使う。

### 会社

会社ごとに自動生成されるチャンネル。名刺登録時に作られる。

### メンバー

全メンバー一覧。名前・役割・「担当◯社 / 未完了◯件」。タップでプロフィール、右のボタンでDM。

**メンバーのアイコンはどこをタップしてもプロフィールが開く。**

## 6. スキャン

中央にSYNCLEシンボルの撮影ボタン、両脇にアルバム・一括読取、下に「手入力で登録する」。

読み取り中はシンボルの周囲に6色のシェイプが外側へ広がる。

### 読み取り結果 → 登録（2ステップ）

**ステップ1：基本情報**
- 既存会社が見つかった場合は警告カード＋「この人を窓口にする」
- 会社名（必須）/ 氏名 / 部署 / 役職 / メール / 電話
- 新規会社なら：業種 / 従業員数
- 手入力なら：売上高 / 所在地 / Web
- **ティア自動判定の結果と根拠を表示**（手動上書き可）

**ステップ2：案件情報**
- 案件種別 / 案件内容 / コメント

### 登録時に自動で起きること

1. 会社を作成（既存なら追加）
2. 会社チャンネルを作成
3. ティアを判定
4. 初回フォロータスクを生成
5. 案件を開始（status='talking'）

### 重複検出

`name_normalized`（法人格と空白を除去）で近いものを探し、候補を提示する。

## 7. タスク

上部タブ3つ：**リスト / カレンダー / メモ**

### リスト

「自分のTODO」と「会社のタスク」を分けて表示。会社ごとにグループ化（設定で担当者ごとに変更可）。

タスクは付箋型（優先度が紙の色、傾きなし）。タップで開いてチェックリストを表示。

### カレンダー

月表示。日付の下に点で予定を示す（緑=打合せ / 赤=高優先 / 青=中 / グレー=低・完了 / 紫=チェックリスト）。

上部に表示範囲の切り替え：**全員 / 自分 / チーム共有**

日付を選ぶと、その日の予定・TODO・タスクが**時刻順の時間割**で並ぶ。時刻なしは「終日」。

### メモ

付箋型。6色から選べる。固定（ピン）で上部に留められる。「タスクにする」でメモをタスクに変換。

### タスクの作成

題名 / 会社 / 担当 / 対象者 / 期限（日付＋時刻、時刻はプリセット5種と「時間なし」）/ 優先度。

**カレンダーの共有先を3つから選ぶ**：
- 自分だけ → 自分のカレンダーのみ
- 担当者 → 担当者のカレンダー
- チーム全員 → 全員のカレンダーに自動反映

「チーム全員」は共有カレンダーへの登録で実現する（`SPEC.md` 6章を参照）。

## 8. 計画（ロードマップ）

部署（全社 / 営業 / インサイドセールス / カスタマーサクセス / 開発）と月（6か月分）で絞り込む。

表示は2つ：**議題 / ロードマップ図**

### 議題

状態で3つに分かれる：話し合い中 / これから話す / 決定済み

各議題に持たせるもの：
- 議題（決めるべき問いの形で書く）
- いつ話すか（未定なら「日程を決める」ボタン）
- 決まったこと（決定済みの場合。緑のカードで表示）
- 参加者（アバター。「変更」で追加・削除）
- やること（チェックリスト。担当者つき）
- 「チャンネルで話す」

### ロードマップ図

部署×月のマス目。各マスにその月の議題数と状態の色。「全社」を選ぶと4部署が縦に並ぶ。

下に選んだ月の議題が縦のタイムラインで並ぶ。

## 9. メール

### 未連携のとき

「Gmail をつなぐと」の説明カード（登録した相手のメールだけ / 広告や請求書は入らない / 返信をタスクにできる）と接続ボタン。

### 連携後

上部に取り込み範囲を常時表示（「登録した相手のメールだけ表示中 / 対象◯人・広告など◯件は対象外」）。

絞り込み：すべて / 未返信 / 受信 / 送信

未返信のメールには「タスクにする」「AIで返信」のボタン。

### AIメール作成

1. 宛先を選ぶ（その会社の名刺から）
2. 用件を選ぶ（本日のお礼 / 面談予約 / 提案書の送付 / 見積のご案内 / フォローアップ / 初回のご挨拶）
3. トーンを選ぶ（かなり丁寧 / 標準 / ややカジュアル）
4. 盛り込みたいことを自由記入
5. 生成 → 修正ボタン（もう少し短く / もっと丁寧に / もっと簡潔でカジュアルに）

**「カレンダーから空き日程を入れる」**で日程調整に飛び、選んだ候補が本文に入る。

**送信すると**：メール履歴に記録 + チャンネルに通知 + タイムラインに記録。

## 10. 日程調整

1. **条件設定**：所要時間（30/45/60/90分）/ 実施形式 / 対象期間（1〜3週間）/ 使うカレンダー
2. **空き時間**：Google Calendar の freebusy から算出。平日10:00〜18:00、12:00〜13:00を除外。最大4つまで選択
3. **アクション**：
   - 「候補を入れてメールを作る」→ メール作成へ
   - 「予約ページを発行」→ URLを生成

### 予約ページ（顧客が見る・未ログイン）

自社名・担当者名・所要時間・形式と、候補の時刻ボタン。

選択すると確定 → カレンダー登録 + 会議リンク発行 + 準備タスク生成 + チャンネル通知 + 確認メール送信。

**セキュリティ**：推測困難なトークン / 有効期限 / 確定後は無効化 / **確定直前にカレンダーを再確認してダブルブッキングを防ぐ**。

## 14. 実装時の判断が必要な箇所

以下は仕様で決めきれていない。実装時に確認すること。

1. **顧客リストの表示形式** — デッキか通常リストか（件数によって出し分けるか）
2. **案件が複数になったときの扱い** — 現状1社1案件。分離のタイミング
3. **金額の持ち方** — 現状は文字列。集計するなら数値化が必要
4. **タスクの期限の意味** — 「◯時までに終わらせる」か「◯時から作業する」か。カレンダーへの入れ方が変わる
5. **書類の種類** — 実際の業務に合わせて増減する
6. **キーパーソンの「層」** — 実際に使う言葉に合わせる
